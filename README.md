# EmCapture
A simple mobile application (currently MVP and only for Android) to capture memorable moments and effortlessly share them with your friends.

## Stack
- [Expo](https://expo.dev/)
- [React Native](https://reactnative.dev/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Nativewind](https://nativewind.dev/)
- [TypeScript](https://www.typescriptlang.org/)
